## 👨‍🏫 프로젝트 소개

본 프로젝트는 **모바일 퍼스트(Mobile-First) 전략**을 기반으로  
**소니 공식 웹사이트를 반응형 웹으로 리뉴얼**한 프로젝트입니다.

사용자의 핵심 목적이 **‘상품 탐색 및 구매’**임을 중심으로  
**직관적인 정보 구조와 스토리텔링 기반 UI**를 설계하여  
브랜드 감성과 사용 편의성을 동시에 강화했습니다.

---

## 🎯 프로젝트 개요

- **기획 방향:** 모바일(360px) 기준 설계 → 태블릿·PC 확장
- **UX 전략:** 상품 탐색 중심 홈 구성 + 내러티브 스크롤 흐름
- **목표:** 다양한 디바이스 환경에서 일관된 사용자 경험 제공

---

## 💡 주요 구현 내용

- **UI/UX 기획**
  - 사용자 여정 분석을 통한 **검색·카테고리 중심 홈 구조 설계**
  - 메인 슬라이드 + 콘텐츠 흐름을 고려한 스토리텔링 레이아웃

- **반응형 구현**
  - CSS **Media Query**를 활용한 모바일 → 데스크탑 대응
  - `rem`, `%`, `vw` 등 상대 단위 기반 유연한 레이아웃 구성

- **인터랙션 개발**
  - `addEventListener`, `classList.toggle`을 활용한  
    메뉴, 팝업, 아코디언, 슬라이드 UI 구현
  - 스크롤 이벤트 기반 동적 콘텐츠 연출

- **UI 시스템 구축**
  - 로그인·회원가입·문의 페이지에 **일관된 컴포넌트 디자인 적용**
  - 유지보수를 고려한 **구조화된 CSS 및 클래스 네이밍**

---

## 🚀 해결한 문제 & 성과

- **문제:**  
  모바일 환경에서 탐색 동선이 복잡하고 콘텐츠에 대한 몰입도가 낮음

- **해결:**  
  모바일 퍼스트 전략을 기반으로 정보 구조를 재설계하고,  
  검색·카테고리 중심의 UI 흐름으로 사용자 탐색 경로를 단순화

- **성과:**  
  - 모바일 기준 상품 탐색 동선 단축 및 탐색 효율 향상  
  - 검색·카테고리 중심 구조로 사용자 탐색 피로도 감소  
  - 스크롤 흐름을 고려한 콘텐츠 배치로 몰입도 있는 사용자 경험 제공  
  - 다양한 해상도에서 일관된 UX 구현  
  - 구조화된 코드 설계로 유지보수성 및 확장성 개선
